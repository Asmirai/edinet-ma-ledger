# 上場企業の M&A 台帳（2016年10月〜2025年9月提出の有価証券報告書から）

`ma_ledger.csv` は、上場企業が有価証券報告書の「企業結合等関係」の注記に書いた買収（取得）を、1行1件にまとめた台帳です。6,405行（親会社と子会社が同じ買収を載せた行を含み、買収としては6,324件）あります。

## 出典と加工

出典：EDINET閲覧（提出）サイト（https://disclosure2.edinet-fsa.go.jp/ ）、公共データ利用規約（第1.0版）（https://www.digital.go.jp/resources/open_data/public_data_license_v1.0 ）

加工：合同会社Asmirai が、EDINET API v2 で取得した有価証券報告書から、AI（Claude）を使って買収の記載を抜き出し、重複をまとめ、のれんの減損・買収後の ROA の変化・買収の目的・業種の関係・買い手の自己資本比率・買い手に対する買収の大きさを付け加えました。国が作成した情報そのものではありません。

この CSV を使うときは、上の出典と加工の記載を表示してください（公共データ利用規約（第1.0版）に準じます）。作り方のコードは https://github.com/Asmirai/edinet-ma-ledger にあります（MIT ライセンス）。

## 列

| 列 | 内容 |
|---|---|
| deal_id | 買収の番号。親会社と子会社が同じ買収を載せたときは同じ番号 |
| primary | 同じ買収を載せた会社のうち、買収前の総資産が小さいほう（直接買った子会社であることが多い）なら True |
| acquirer_edinet_code・acquirer_sec_code・acquirer_name | 買い手の EDINET コード・証券コード・名前 |
| acquirer_industry | 買い手の業種（EDINET コードリストの「提出者業種」） |
| acquiree_name・acquiree_business | 買われた会社（または事業）の名前と事業の内容（注記の記載から） |
| acquisition_date | 企業結合日 |
| legal_form・voting_ratio | 法的形式と、取得後の議決権比率（注記の記載のまま） |
| consideration_yen・goodwill_yen・assets_total_yen | 取得原価・のれん・受け入れた資産の合計（円に換算） |
| size_ratio | 取得原価 ÷ 買い手の買収前の期の総資産 |
| acquirer_equity_ratio | 買い手の自己資本比率（買収の直前の期の有価証券報告書から読んだ値）。primary が True の行に付ける。直前の期の有価証券報告書が手元に無い行は空 |
| purpose・relatedness | 買収の目的と、買い手との業種の関係（同業種・関連業種・異業種）。注記の「企業結合を行った主な理由」を AI で分類した。primary が True で、base_year が2022年までの行だけに付ける。ほかは空 |
| base_year | 企業結合日を含む事業年度の決算日の年 |
| delta_roa | 買い手の ROA の変化（買収後3期の平均 − 買収前の期） |
| roa_beat_peers | 買収前の ROA が同じ水準の上場会社より ROA が伸びたら True。総資産の10%未満の買収では、買収の影響はほとんど表れない |
| goodwill_impaired | 買収した期から3期後までに、その買収ののれんを減損したら True。primary が True で、のれんが生じた行だけを判定する。のれんが無い行と primary が False の行は空 |
| goodwill_impaired_note | 減損を判定できなかった理由（3期後の有報が無い、事業譲受、名前が短すぎる） |
| source_doc_ids | 出典の有価証券報告書の書類番号（EDINET の docID） |

## 注意

- AI が抜き出した値を含みます。名前と金額が原文に載っているかはプログラムで照合し、重複をまとめる前の取得の99.3%で照合が通りました。ただし、別の欄の数字を拾う誤りはあり得ます。AI（Claude Opus）が原文と見比べた156件の抜き取りでは、取得原価の誤りは2件（1.3%）でした。この採点のうち30件は ChatGPT（OpenAI）にも同じ規則で採点させて突き合わせ、食い違った項目は原文で確かめて直しています。人による確認はまだしていません。
- 取得原価の単位を読み違えた行（円と千円の取り違えなど）が一部に残っています。
- のれんの減損は、有価証券報告書に相手の名前と並べて書かれたものだけを拾っています。拾えていない減損があり、実際より少なめに出ている可能性があります。
- 上場企業が買い手で、有価証券報告書の注記に載った買収だけです。重要性が乏しいとして注記を省いた買収は入っていません。
