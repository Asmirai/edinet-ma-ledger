# 予測モデルを、公開 CSV から学習する

- issue：#34
- PR：#36

## 決めたこと

予測モデル（`ledger/scorer.py`）は、公開 CSV（`data/public/ma_ledger.csv`、Release の `ma_ledger.csv`）だけから学習する。記事の図のうち、モデルを使う3枚も同じ CSV から作る。

## なぜ

| 決めたこと | なぜ |
|---|---|
| 学習の入力を公開 CSV だけにする | 以前は、公開していない `data/` の中間ファイル（減損・目的・業種・買い手の財務）を読んでいた。記事の「自分で試すには」のコマンドが、Release の CSV を取っただけでは動かなかった |
| 公開 CSV に、買い手の自己資本比率の列（`acquirer_equity_ratio`）を足す | モデルの4つの変数のうち、公開 CSV に無かったのはこの列だけだった |
| CSV が無いときは、Release の URL を出して止める | 何を取ってどこに置けばよいかを、エラーの文で伝えるため |
| 図も、モデルと同じ CSV から作る | 記事の図とモデルの数字が、別のデータから作られて食い違うのを防ぐ |

## 経緯

切り替えの前と後で、結果が変わらないことを確かめた。`data/scorer.md`（学習850件、確かめ869件、AUC 0.687、5つの群の失敗率）と、記事の候補4社の確率（9.0%・18.3%・20.7%・34.2%）は1文字も変わらず、記事の図6枚はバイト単位で同じだった。

変数を4つにとどめたことも、この決定と合っている。同じ学習と確かめの分け方で、目的・対価の種類・買い手の現金比率・買収前の ROA を足しても、AUC は0.684で4つの0.687とほとんど変わらなかった（公開していない中間データで計算した）ので、公開 CSV に載せる列を増やさずに済んだ。
