# 買収の成否を、のれんの減損で測る

- issue：#17
- PR：#16（ROA で測ったモデル）、#19（減損への切り替え）

## 決めたこと

予測モデルの目的変数を、買い手全体の ROA の変化ではなく、買収から3年以内にその買収ののれんを減損したかにする。

## なぜ

| 決めたこと | なぜ |
|---|---|
| 買い手全体の ROA の変化を目的変数にしない | ROA で測った成否を当てるモデルは、AUC 0.51 で使えなかった（#16） |
| ROA で当てられない原因を、買収の大きさと見る | 買収の約半分は、取得原価が買い手の総資産の2%未満だった。この大きさでは、買収の結果が会社全体の利益の動きに表れない |
| のれんの減損を目的変数にする | その買収で生じたのれんに結び付いた結果なので、小さい買収でも判定できる。のれんが生じ、3期後の有価証券報告書がそろう2,429件で判定でき、15.6% が減損した |

## 経緯

#16 で、買収の時点で分かる情報から、ROA で測った成否を当てようとした。ロジスティック回帰も勾配ブースティングも AUC 0.51 で、全件の成功率を出すだけのモデルと変わらなかった。

#19 で、のれんの減損と、大きい買収（取得原価が総資産の10%以上、299件）の ROA の2つを目的変数にした。大きい買収の ROA は、確かめに使える案件が120件ほどしかなく、変数を足す前と後の AUC の差（0.70→0.73）が誤差の範囲に収まった。記事のモデル（#27）は、減損だけを目的変数にした。

減損には限界がある。有価証券報告書に決まった置き場所が無く、相手の名前と並べて書かれた減損だけを拾うので、実際より少なめに出ている可能性がある。のれんが生じない買収と、減損に至らない失敗は測れない。
