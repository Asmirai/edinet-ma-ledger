# 買収で生じたのれんを、あとで減損したかを確かめる

入力ファイル（JSONL、1行1案件）を Read で全部読む。各行には次が入っている。

- `key`：案件の番号
- `acquirer`：買った会社の名前
- `acquiree_name`：買われた会社（または事業）の名前
- `base_year`：買収した事業年度の決算日の年
- `passages`：買った会社の、買収した年から3期後までの有報から、「減損」と相手の名前の両方を含む箇所を抜き出したもの（`periodEnd` はその有報の決算日）

コードやスクリプトは書かない・実行しない。自分で読んで判断する。

## 判断のしかた

`impaired` を true にするのは、**この買収で生じたのれん（またはこの相手に関するのれん）を、減損損失として計上した**と読める場合だけ。

- true の例：「株式会社〇〇に係るのれんについて減損損失を計上」「減損損失の内訳：〇〇（場所）、のれん」「〇〇の株式取得時に計上したのれんの全額を減損」
- false の例：
  - のれんの償却（毎期の費用）だけが書かれている
  - 「減損の兆候はない」「減損損失を認識していない」
  - 相手の会社の建物・設備など、のれん以外の資産の減損
  - 別の会社ののれんの減損で、たまたま近くに相手の名前があるだけ
  - 相手の名前が、別の会社の名前の一部として出ているだけ
- 前の期に買った同じ相手を、また買った場合など、この買収と別の取引ののれんだと読めるときは false

## 出力

出力ファイルに Write で JSON を1つ書く。入力の全行について1要素ずつ、入力と同じ順で出す。

```json
[{"key": "52-E05083", "impaired": true, "periodEnd": "2016-08-31", "reason": "オーケー企画に係るのれんの減損損失を計上"},
 {"key": "53-E01234", "impaired": false, "periodEnd": null, "reason": "償却の記載だけ"}]
```

`periodEnd` は減損を計上した有報の決算日（false なら null）。`reason` は短い日本語で1文。

最後に、件数と true の件数を1行で返す。
