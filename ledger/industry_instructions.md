# 買われた会社の業種を、事業の内容から東証の33業種に分ける

入力ファイル（JSONL、1行1件）を Read で全部読む。各行には次が入っている。

- `key`：案件の番号
- `acquirer`：買った会社の名前
- `acquiree_name`：買われた会社（または事業）の名前
- `business`：有報に書かれた、買われた会社の事業の内容

コードやスクリプトは書かない・実行しない。自分で読んで判断する。

## 分け方

`business`（無ければ `acquiree_name`）から、買われた会社の主な事業を、次の33業種のどれか1つに分ける。書き方は下のとおりに写す。

水産・農林業／鉱業／建設業／食料品／繊維製品／パルプ・紙／化学／医薬品／石油・石炭製品／ゴム製品／ガラス・土石製品／鉄鋼／非鉄金属／金属製品／機械／電気機器／輸送用機器／精密機器／その他製品／電気・ガス業／陸運業／海運業／空運業／倉庫・運輸関連／情報・通信業／卸売業／小売業／銀行業／証券、商品先物取引業／保険業／その他金融業／不動産業／サービス業

- 複数の事業が書かれていれば、最初に書かれた事業か、名前から主と読める事業で分ける
- 作る会社は製造業の業種、仕入れて売る会社は卸売業（会社や店に売る）か小売業（消費者に売る）
- ソフトウェアの開発・情報処理・通信・放送・出版・広告のうちインターネットの媒体は情報・通信業。人材派遣・コンサルティング・広告代理・飲食・介護・教育などはサービス業
- 買った会社の業種に引きずられない。`acquirer` は、事業の内容が短すぎて読めないときの手がかりにだけ使う
- 事業の内容が無く、名前からも分からなければ null

## 出力

出力ファイルに Write で JSON を1つ書く。入力の全行について1要素ずつ、入力と同じ順で出す。

```json
[{"key": "123-E01234", "industry": "情報・通信業"}, {"key": "124-E05678", "industry": null}]
```

最後に、件数と、null にした件数を1行で返す。
